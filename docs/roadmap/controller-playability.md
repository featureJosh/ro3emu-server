# Controller playability matrix

Is every feature of the game doable with only a gamepad? First audit 2026-10-16 (workflow `wf_06c184a1-225`): six
Haiku scanners read the client Lua (`re/clientB/lua-src/UI`, `Logic`) against our hooks (`src/Ro3Emu.ClientHooks`),
and six independent Haiku verifiers re-checked every row (✔ confirmed, ✎ corrected, ? unverified). **Static code
reading only: nothing here was tried in game.** Rows marked ❌/🟡/❓ are the controller backlog; tick them in
[controller.md](controller.md) when fixed and verified.

Status at audit time, before round 1 merged: skill binding, potion/D-pad assignment, quest auto-path and the full Select
wheel were fixed in round 1 afterwards (see ROADMAP); their rows below describe the state before the fix.

Legend: ✅ fully doable by pad · 🟡 reachable but some action needs mouse/keyboard · ❌ not doable · ❓ cannot tell from code

**Totals:** ✅ Yes 66, 🟡 Partial 51, ❌ No 15, ❓ Unknown 39 (171 rows; 59 more features listed as not yet audited).
